## [0.1.0] - 2026-07-12

### Added

- JSON configuration for one or more endpoint checks.
- Expected HTTP status and dotted JSON-path assertions.
- Human-readable and machine-readable output formats.
- Stable exit codes for local scripts and CI.
- Unit, integration, and end-to-end tests with an 80% coverage gate.
- Strict configuration validation, redirect-status checks, and query redaction.
- A real production configuration and scheduled monitor for TGWise.
- Contributor templates, maintenance policy, roadmap, and package metadata.
