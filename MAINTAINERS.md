# Maintainers

## Current maintainer

- [traxy111](https://github.com/traxy111) — primary maintainer and release owner

## Maintenance commitments

- Triage reproducible bug reports within seven days.
- Review focused pull requests after required CI checks pass.
- Publish security fixes for the latest release and disclose them responsibly.
- Keep runtime dependencies at zero unless a clear, reviewed use case requires
  otherwise.

Releases follow semantic versioning. Until version 1.0, minor releases may
change configuration details when the changelog and migration guidance document
the change.
